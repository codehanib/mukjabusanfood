# 🍗 묵자 (MUKJA)
Spring Boot를 활용한 부산 식당 예약 & 배달 주문 사이트

## 프로젝트 소개
부산 내 식당의 카테고리별 조회와 예약, 배달 주문이 가능한 사이트를 구현한 프로젝트입니다.

비회원 : 식당 예약, 조회 <br>
회원 : 식당 예약 및 배달 주문, 예약과 주문 내역 조회, 북마크(찜), 1:1 문의와 리뷰 작성 <br>
점주 : 입점 식당 등록, 식당에 들어온 예약과 주문 관리, 1:1 문의 작성 <br>
관리자 : 회원 정보와 권한 관리, 식당 삭제, 공지사항 작성, 1:1 문의 답변

- 프로젝트 기간 : 2026.08.28 ~ 2026.09.22

## 주요 기능
### 회원
- 회원 가입
- 로그인 / 로그아웃
- 회원 정보 조회 및 수정
- 회원 탈퇴

### 점주
- 회원 가입
- 로그인 / 로그아웃
- 입점 식당 등록
- 식당 정보 수정

### 식당
- 식당 목록 조회
- 카테고리별 식당 조회
- 식당명˙지역˙음식 종류˙메뉴명 등의 조건으로 검색 기능
- 식당 상세 정보, 메뉴, 위치 등 조회
- 식당에 대한 리뷰 작성, 조회
- 식당 북마크 기능

### 예약
- 식당 예약 (비회원, 회원 가능)
- 비회원 예약 조회
- 예약 조회, 예약일 수정
- 예약금 결제

### 배달 주문
- 식당 배달 주문 (회원 가능)
- 장바구니에는 한 식당의 메뉴만 추가 가능
- 주문 결제
- 배달원 위치 조회

### 게시판
- 1:1 문의 등록, 수정, 삭제
- 본인이 등록한 문의만 조회
- 공지사항 조회
  
### 관리자
- 회원 정보 관리
- 입점 식당 관리
- 사이트 내 주문 정보 관리
- 공지사항 등록
- 1:1 문의 답변
- Elastic search 통계 대시보드 조회

## 팀원

## Git 협업 규칙
- 메인 `master` 브랜치 직접 Push 금지
- 개인 브랜치에서만 작업
- 작업 완료 후 message 작성하여 Commit
- GitHub에 Push
- Pull Request 생성
- 팀장은 팀원이 수정한 코드 리뷰 후 `master` Merge
- 항상 GitHub에서 최신 파일 pull 후 작업
